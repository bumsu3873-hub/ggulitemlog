1. 웹사이트 (ggulitemlog.vercel.app)

  • 이 사이트는 회원가입이 없고, 이름·이메일 같은 개인정보를 받지 않습니다.
  • 방문 통계를 위해 Vercel Web Analytics를 사용합니다. 쿠키 없이 페이지 조회 수, 유입 경로, 기기·국가 정보를 익명으로 집계하며, 개인을 식별하지 않습니다.
  • 상품 링크는 네이버 쇼핑 커넥트 제휴 링크입니다. 링크를 눌러 이동한 뒤의 정보 처리는 네이버의 개인정보처리방침을 따릅니다.

2. 업로드 도구 (YouTube API 서비스 사용)

  • 세꿀사는 채널 운영자 본인의 영상을 본인 유튜브 채널에 예약 업로드하기 위해 YouTube API 서비스를 사용하는 개인용 도구를 운영합니다. 다른 사용자에게 제공하지 않습니다.
  • 이 도구는 운영자 본인 계정의 OAuth 인증 토큰만 운영자의 PC에 저장하며, 다른 사람의 데이터는 수집·저장·공유하지 않습니다.
  • 이 도구는 YouTube 서비스 약관(https://www.youtube.com/t/terms)을 따르며, Google 개인정보처리방침(https://policies.google.com/privacy)이 적용됩니다.
  • 권한은 Google 보안 설정 페이지(https://myaccount.google.com/permissions)에서 언제든 해제할 수 있습니다.

3. 보관 및 삭제

  • 업로드 도구의 OAuth 토큰은 운영자 PC에만 보관하며, 도구 사용을 중단하면 즉시 삭제합니다.
  • Google 보안 설정 페이지(https://myaccount.google.com/permissions)에서 접근 권한을 해제하면 토큰은 더 이상 사용할 수 없습니다.

Privacy Policy

Effective date: November 12, 2026

1. Website

This site has no accounts and does not collect personal information such as names or emails. It uses Vercel Web Analytics, which collects anonymous, cookie-free page view, referrer, device, and country statistics. Product links are Naver Shopping Connect affiliate links. After you leave this site, Naver's privacy policy applies.

2. Upload tool (uses YouTube API Services)

Sekkulsa runs a personal tool that uses YouTube API Services to upload and schedule the channel owner's own videos to the owner's own YouTube channel. It is not offered to other users. The tool stores only the owner's OAuth token, locally on the owner's PC. It does not collect, store, or share anyone else's data. By using it, the owner agrees to the YouTube Terms of Service (https://www.youtube.com/t/terms). The Google Privacy Policy (https://policies.google.com/privacy) also applies. Access can be revoked at any time at https://myaccount.google.com/permissions.

3. Retention and deletion

The OAuth token is stored only on the owner's PC and is deleted as soon as the tool is no longer used. Revoking access at https://myaccount.google.com/permissions makes the token unusable. Data received from YouTube API Services (video status, used to check scheduled publish times) is used in memory only while the tool runs and is never stored. Deletion requests sent to the contact below are handled within 7 days.
